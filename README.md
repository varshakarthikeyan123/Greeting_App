# Greeting App – Spring Boot REST API

## Description
This project is a Spring Boot application that implements a Greeting App with multiple REST APIs.  
The application demonstrates how to build RESTful web services using Spring Boot, MySQL, and Spring Data JPA.

## Technologies Used
- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- MySQL
- Maven
- Git & Git Flow
- Postman / Curl for API Testing

## Database
Database Name: greetingdb
